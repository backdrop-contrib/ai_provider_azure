# AI Provider Azure

Connect Azure-hosted models to Backdrop for chat, image analysis, embeddings, or image generation. You choose which Azure deployments your site can use.

## Installation

Install and enable this module with AI and Key. [Backdrop module installation guide](https://backdropcms.org/user-guide/modules)

Store your service credentials using the Key module. Choose the provider in **Configuration → AI → Settings → Providers**. [Setup and troubleshooting](https://github.com/backdrop-contrib/ai_provider_azure/wiki)
